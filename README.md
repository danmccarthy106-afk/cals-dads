# Essence of Dreams Trip Planner

Group planning site for the Playa Hermosa villa trip. Seven families rank excursions,
set chef / bartender / dining-out preferences and see the group tally live.

- `index.html` — the whole site (static; hosted on GitHub Pages)
- `firestore.rules` — Firestore rules for the `families` collection (Firebase project `essence-trip-planner-2026`)

Deploy rules: `firebase deploy --only firestore:rules`
